# Changelog

## 0.3.0

- Support host-owned composition of the public math controls and canvases.
- Add initial 3D scene and camera inputs plus scene update callbacks for external hosts.
- Preserve canvas `GlobalKey` controls; use `MathDrawingController` for complete workspace commands and snapshots.

## 0.1.2

- Add 2D graph view controls and formula domains with characteristic points.
- Expand workspace composition, state snapshots, persistence, and presentation controls.
- Improve math keyboard navigation, clipboard handling, and parameter controls.
- Update the example startup experience and integration documentation.

## 0.1.1

- Fix the bundled MathLive editor asset path for the `visual_math` package name.
- Move the add-formula action to the app bar and remove the duplicate view-reset action.

## 0.1.0

- Initial public release of the `visual_math` Flutter package.

# Visual Math 0.2 Development Plan

`v0.2` is the planned drawing-save milestone for Visual Math. This is an initial high-level scope; refine file format, storage limits, and interaction details before implementation.

## Goal

Let users save a drawing result inside the app and open it again later.

## Scope

- Save each drawing result as an app-internal file with the `.v` suffix.
- Add a Files page to the app's navigation and list saved drawing files there.
- Open a saved file from the Files page and show its drawing again.

## Acceptance Criteria

- A user can save a drawing as a `.v` file within the app.
- The Files page shows saved files, and selecting a file reopens its saved drawing.
- The saved drawing can be viewed again after leaving and returning to the Files page.

## Follow-up

Define the `.v` format, save and overwrite behavior, file naming, and deletion or import/export behavior in later planning before implementation.

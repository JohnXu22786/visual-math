# v0.3 显示能力现状清单

基准：`v0.3` 分支 052682a。本文记录已有实现，不扩大或改变公开 API 的兼容性承诺。现有包名为 `visual_math`；入口 `lib/visual_math.dart` 导出下列组件和模型，`lib/dart_math.dart` 是兼容入口。具体 v0.3 支持范围仍需用户确认。

| 显示能力 | 实现及模型 | 当前复用方式和导出情况 |
| --- | --- | --- |
| 2D 显式函数和隐式等式零集 | `lib/src/widgets/math_canvas.dart` 的 `MathCanvas`、`GraphPainter`；`math_expression.dart` 的 `MathExpression`、`MathExpressionType`；`formula_entry.dart` | 主入口导出。宿主可嵌入画布，以初始表达式或 `MathCanvasState` 的 `setExpression`、`setFormulas` 更新；支持视口、缩放、手势和回调。绘制依赖数值采样，不能据此承诺所有表达式均可精确显示。 |
| 3D 曲面与参数曲线、参数曲面 | `math_canvas_3d.dart` 的 `MathCanvas3D`；`math_expression_3d.dart` 的 `Expression3D`；`math_3d_object.dart` 的网格和对象 | 主入口导出。宿主可嵌入画布，并通过 `MathCanvas3DState` 设置曲面或对象、相机与视图；模型支持显式曲面及参数曲线/曲面。 |
| 3D 几何对象 | `math_3d_object.dart` 的 `Object3D`、`Point3D`、`Vector3D` 等；`math_3d_scene.dart`；`math_canvas_3d.dart` | 主入口导出。对象类型包括点、线、平面、曲面、球、多面体、向量和曲线；画布提供场景、选择和创建相关操作及回调。构造工具另见 `math_3d_construction.dart`、`math_3d_tool.dart`。 |
| 完整绘图工作区 | `lib/src/pages/math_drawing_page.dart` 的 `MathDrawingPage`；`math_drawing_controller.dart`、`math_drawing_state.dart`、`math_workspace_options.dart`、`math_workspace_capabilities.dart` | 主入口导出。页面组合编辑、2D/3D 视图和工具；宿主可使用 controller、options 和 capabilities 集成，页面拥有其编辑资源。 |
| 数学输入与控制组件 | `math_formula_field.dart`、`math_keyboard.dart`、`math_parameter_controls.dart`、`math_3d_toolbar.dart` | 主入口导出。宿主自行组合并连接输入、参数和工具回调；它们并非独立的绘图结果契约。公式编辑器的平台限制见 README 的平台支持说明。 |
| WebView 2D 画布 | `math_canvas_webview.dart` 的 `MathCanvasWebView` | 主入口导出类，但隐藏该文件的通用回调 typedef；这是独立于原生 `MathCanvas` 的 JSXGraph 画布，存在网络依赖，详见 README。 |

## 契约决策所需信息

已有 README 的集成说明和现有导出可作为起点，但不自动决定 v0.3 的稳定 SDK 表面。需确认：支持哪些显示类型；宿主如何提供和更新数据、配置视图并接收事件；交互及平台支持范围；是否沿用现有模型、controller 和兼容入口；是否需要 v0.2 的共享模型或文件格式。确认后才能按路线图实现、编写外部 consumer 示例并验收兼容性。

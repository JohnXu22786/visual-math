# Visual Math 0.3 开发计划

`v0.3` 聚焦将 Visual Math 的显示能力作为 MathSDK 提供给外部 Flutter 应用。各项工作通过相关 issue 和 pull request 跟踪；可选用 GitHub milestone 汇总并链接本计划。

## 目标

明确并交付经用户确认的公开 SDK 契约，使外部 Flutter 应用能够独立使用选定的数学显示能力。

## 里程碑

### 1. 清点现有显示能力

**依赖：** 无。

**范围：** 盘点现有可渲染的显示类型，以及对应的 widgets、models 和导出入口。

**退出条件：** 清单记录各显示类型的实现位置、当前复用方式及现有导出情况，供公开 API 决策参考；清点结果本身不承诺公开任何类型。

### 2. 确认公开 SDK 契约

**依赖：** 里程碑 1。

**范围：** 由用户决定要支持的显示能力及其公开 API 契约，包括输入、配置、事件/回调和公开入口。若需要共享 v0.2 的模型或文件格式，应在此阶段明确该依赖；目前不假定存在此依赖。

**退出条件：** 用户确认的契约及支持范围已书面记录；任何所需的 v0.2 共享模型或文件格式依赖已明确。实现所需的 API 选择保持待决，直到本里程碑完成。

### 3. 实现选定的公开 package 接口

**依赖：** 里程碑 2；若该里程碑确认需要共享模型或文件格式，也依赖对应的 v0.2 工作。

**范围：** 按确认的契约实现公开 package 表面，并将非公开实现细节与稳定 API 区分开。

**退出条件：** 外部 Flutter 调用方可通过确认的入口使用约定的显示能力，行为符合已记录的输入和事件契约。

### 4. 外部 Flutter 使用示例与文档

**依赖：** 里程碑 2 和 3。

**范围：** 提供外部 Flutter consumer 示例和文档，说明依赖配置、公开导入、显示能力选择及契约约定。

**退出条件：** 开发者可依据文档在独立 Flutter 应用中完成一个选定显示能力的集成；示例与公开 API 一致。

### 5. 兼容性与发布验收

**依赖：** 里程碑 3 和 4；若实现使用 v0.2 共享模型或文件格式，也依赖相应工作。

**范围：** 验证包构建、外部 consumer 集成及已公布的兼容性承诺，并整理发布所需信息。

**退出条件：** 验证结果符合已确认的 API 和兼容性约定；发布说明清楚列出支持范围及限制。

## 范围边界

- 具体 API 签名、序列化模型、交互方式及公开的显示类型均由用户决策；本计划不预先选定。
- 在用户确认公开契约前，不开始依赖 API 选择的实现工作。
- v0.2 不是既定前置条件；只有确认需要共享模型或文件格式时，才建立对应依赖。
- 本版本聚焦外部应用嵌入显示能力，不承诺重做绘图编辑器或提供完整应用级导航。

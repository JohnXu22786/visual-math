# v0.3 embedded display contract

The supported entry point is `package:visual_math/visual_math.dart` in the
existing `visual_math` package. `package:visual_math/dart_math.dart` remains a
compatibility export. Existing exports are retained; this contract identifies
the embedded display surface, rather than removing other existing APIs.

* `MathCanvas` displays explicit 2D functions and implicit equation contours.
  The host may set an initial expression, replace expressions or formulas via
  `MathCanvasState`, control the viewport and gestures, and receive ready,
  coordinate, viewport and error callbacks. Invalid `setExpression` input
  reports an error and leaves the previous plot in place. Curves are sampled,
  so finite resolution and numerical limits apply.
* `MathCanvas3D` displays the existing `Object3D` geometry and meshes, including
  surfaces and curves. The host may replace objects via `MathCanvas3DState`,
  configure the camera, projection, visibility and gestures, and receive the
  existing scene, selection, viewport and ready callbacks. `Expression3D`
  provides the existing surface and parametric sampling models.
* Hosts own their keys and surrounding UI. State methods are available only
  while the widget is mounted; use `onReady` for initial imperative setup and
  stop calling the state after disposal. Canvas interaction state is owned by
  the widget. Inputs, callback signatures and further methods are documented
  on the exported types and in the README.

This version reuses existing package models and does not require v0.2 shared
models or a file format. It does not promise symbolic accuracy, complete
mathematical coverage, a serialization interchange format, or that WebView,
editor and complete-workspace APIs are part of this embedded display contract.
Existing APIs remain available. Platform and dependency requirements follow
`pubspec.yaml` and the README; actual platform verification is reported
separately. See `examples/sdk_consumer` for a standalone host.
